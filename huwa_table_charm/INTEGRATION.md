# HUWA integrated app — 15 October 2026

Current release: 17 researched Table Charm products with locally packaged photos, optional approximate 3D previews, a real database-backed product enquiry flow, and a protected admin enquiry inbox at /admin/inquiries.

Earlier sample and concept products are archived. Unknown local prices use price-on-request and are blocked from cart and checkout. Official source metadata lives in backend/catalog/table-charm.json. Enquiries are stored for staff follow-up; no automatic customer messages are sent.

Run node dev.mjs from this folder and open http://127.0.0.1:5175/. Production preparation is documented in RELEASE-2026-10-15.md. The application has not yet been deployed publicly.
